Route: `/backlinks`.

## What it does

Enter any domain and get its total backlink count, referring domain count,
a 0–100 domain rating, and up to 200 individual referring links from the
built-in backlink index, in a single lookup. This is a stateless, one-off
search — no tracked-list concept, just type a domain and get its backlink
summary; a small recent-searches list (project-scoped) lets you re-run a
past lookup with one click.

This is the same backlink data shown per-competitor on the
[Competitor Research](/docs/competitors) page's "Backlink profile" card, but
surfaced as its own standalone module for a quick one-off check.

## What's real today

- **The overview lookup**: real, no mock fallback. `@seo-tool/dataforseo`'s
  `getBacklinksOverview(domain)` calls DataForSEO's `backlinks/summary/live`
  and throws `DataForSeoNotConfiguredError` when `DATAFORSEO_LOGIN` /
  `DATAFORSEO_PASSWORD` aren't set (`isDataForSeoConfigured()`) — there is no
  deterministic-mock path left in `packages/dataforseo/src/client.ts` for
  this call, and a failed live call also throws rather than silently
  returning fake numbers. `domainRating` is DataForSEO's own 0–1000 domain
  rank, normalized to a 0–100 scale. The page no longer shows a "Mock data"
  badge — a lookup only ever succeeds with real data or fails with a
  visible error.
- **The individual backlinks list**: also real, not a stub.
  `@seo-tool/dataforseo`'s `getBacklinksList(domain)` calls DataForSEO's
  `backlinks/backlinks/live` for up to 200 real referring links per domain
  (source domain/URL, anchor text, dofollow/nofollow, domain-from rank, spam
  score, first-seen/last-seen dates, new/lost flags), rendered in a
  sortable, searchable table (`BacklinksTable`) with dofollow/nofollow and
  quality filters (spam score ≥ 30 = spam, ≥ 10 or domain rank < 100 =
  warning, otherwise good) and a per-row "Add to Outreach" action. Unlike
  the overview call, a missing config or a failed live call here returns an
  empty array rather than throwing, so a partial failure doesn't take down
  the whole page.
- **Domain validation/normalization**: real — reuses
  `apps/web/components/competitors/domain-utils.ts` (`normalizeDomain` /
  `isValidDomain`), the same helper the Competitor Research and Domain
  Overview pages use.
- **Caching, not mocking**: a successful lookup is cached per project for 7
  days in the `backlinksCache` table (same staleness convention as Keyword
  Research's keyword-metrics cache) so repeat searches for the same domain
  don't re-hit DataForSEO every time and past lookups survive as real
  history. A cache hit shows a "Cached" badge next to the domain heading —
  this is the only badge the page shows; it reflects cache freshness, not
  data authenticity.
- **Still a lightweight estimate, not a full audit**: the page calls this
  out with a "Not a full backlink audit" note — this index is a directional
  signal, not as deep as a specialized tool like Ahrefs, matching the same
  caveat already shown on the Competitor Research detail view.

## Components

- `apps/web/app/(dashboard)/backlinks/actions.ts` — `fetchBacklinksOverview`
  Server Action: normalizes/validates the domain, checks the project-scoped
  `backlinksCache` for a fresh (< 7 day) row, and otherwise calls
  `getBacklinksOverview` + `getBacklinksList` together and upserts the
  result into the cache.
- `apps/web/app/(dashboard)/backlinks/page.tsx` — server component; loads
  the project's last 10 cached lookups as recent-search history and renders
  `PageHeader` + the workspace.
- `apps/web/components/backlinks/backlinks-workspace.tsx` — client
  component: domain search input, recent-searches list, loading/error
  states, and `MetricCard`s for total backlinks, referring domains, and
  domain rating.
- `apps/web/components/backlinks/backlinks-table.tsx` — client component:
  the individual-backlinks table with search, dofollow/nofollow and quality
  filters, and the "Add to Outreach" action.
- `apps/web/components/backlinks/backlink-quality-badge.tsx` — renders the
  spam-score/domain-rank-derived quality badge (good/warning/spam) used in
  the table.
