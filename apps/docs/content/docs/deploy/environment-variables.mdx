---
title: Environment Variables
description: Every variable RosterSEO reads, what it does, and whether it's required
---

Every variable below comes straight from `.env.example` at the repo root —
copy that file to `.env` and fill in what you need. Nothing marked
"optional" blocks the app from starting; each just stays inert (a real
"not connected" state, never fake data) until set.

## Mode

| Variable | Required | What it does |
|---|---|---|
| `SELF_HOSTED` | Yes | `true` = single-tenant, no billing, your own API keys — the only mode that actually exists today. `false` is reserved for a planned multi-tenant hosted SaaS mode that isn't implemented yet; this var isn't read anywhere in the app currently, so setting it to `false` changes nothing. |

## Database

| Variable | Required | What it does |
|---|---|---|
| `DATABASE_URL` | Yes | The app's runtime connection — **must** be a restricted, non-superuser role or Postgres row-level security silently does nothing. See [Self-Hosting](/docs/deploy/self-hosting#database-roles). |
| `DATABASE_MIGRATE_URL` | No | Elevated role for running migrations (DDL needs owner/superuser). Falls back to `DATABASE_URL` if unset. |

## Auth

| Variable | Required | What it does |
|---|---|---|
| `BETTER_AUTH_SECRET` | Yes | Random secret signing session tokens. Generate with `openssl rand -hex 32`. |
| `BETTER_AUTH_URL` | Yes | The app's real public URL, server-side. |
| `NEXT_PUBLIC_BETTER_AUTH_URL` | Yes | Same URL, exposed to the browser. Usually identical to the above. |
| `APP_URL` | No | Same public URL again, for background processes (MCP server, IndexNow) with no inbound request to read an origin from. |

## SEO data provider

| Variable | Required | What it does |
|---|---|---|
| `DATAFORSEO_LOGIN` / `DATAFORSEO_PASSWORD` | No | Raw DataForSEO credentials (not a pre-encoded token) — powers keyword/SERP/backlink data across most SEO tools. |

## AI visibility providers

| Variable | Required | What it does |
|---|---|---|
| `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `GOOGLE_AI_API_KEY` / `PERPLEXITY_API_KEY` | No | Direct-API AI Visibility providers — set any subset you want tracked. |
| `BRIGHTDATA_API_TOKEN` | No | Real scraped ChatGPT/Gemini/Perplexity/Copilot + Google AI Overview samples. |
| `BRIGHTDATA_SERP_ZONE` | No | Required alongside the token above specifically for Google AI Overview — must match a real zone name from your BrightData dashboard, or you'll get a "zone not found" error. |
| `OPENROUTER_API_KEY` | No | One key, gateway to any OpenRouter-hosted model. |
| `OPPORTUNITIES_OPENROUTER_MODEL` / `PAGE_ANALYZER_OPENROUTER_MODEL` | No | Override which OpenRouter model those two features use — real defaults, only needed to try a different model. |

## Google OAuth (GSC + GA4 + Merchant Center)

| Variable | Required | What it does |
|---|---|---|
| `GOOGLE_OAUTH_CLIENT_ID` / `GOOGLE_OAUTH_CLIENT_SECRET` | No | Enables connecting Search Console, GA4, and Merchant Center. See [Connected Data → Integrations](/docs/connected-data/integrations). |
| `GOOGLE_OAUTH_REDIRECT_URI` | No | Override the callback URL — only needed if it can't be derived correctly (e.g. behind a proxy that changes the host). |
| `GOOGLE_PAGESPEED_API_KEY` | No | Raises the PageSpeed Insights rate limit for Site Audit / Page Analyzer (works unauthenticated too, just slower). |
| `BING_WEBMASTER_API_KEY` | No | One workspace-wide key for Bing Webmaster Tools data. |

## Publish OAuth (blog platforms)

Every platform here also works via a manually-pasted token with none of
this set — see each platform's own guide under [Publish](/docs/publish/overview)
for exactly where to get one. These only enable the one-click **Connect**
button.

| Variable | What it does |
|---|---|
| `WORDPRESS_COM_CLIENT_ID` / `WORDPRESS_COM_CLIENT_SECRET` | [WordPress.com](/docs/publish/wordpress-com) one-click connect |
| `TUMBLR_CLIENT_ID` / `TUMBLR_CLIENT_SECRET` | [Tumblr](/docs/publish/tumblr) one-click connect |
| `HUBSPOT_CLIENT_ID` / `HUBSPOT_CLIENT_SECRET` | [HubSpot](/docs/publish/hubspot) one-click connect |
| `WEBFLOW_CLIENT_ID` / `WEBFLOW_CLIENT_SECRET` | [Webflow](/docs/publish/webflow) one-click connect |
| `SHOPIFY_CLIENT_ID` / `SHOPIFY_CLIENT_SECRET` | [Shopify](/docs/publish/shopify) one-click connect |

## Social OAuth

Bluesky and Mastodon need none of this — see [Social](/docs/social/overview).
Every other platform falls back to a manual token when unset.

| Variable | What it does |
|---|---|
| `LINKEDIN_CLIENT_ID` / `LINKEDIN_CLIENT_SECRET` | [LinkedIn](/docs/social/linkedin) one-click connect |
| `PINTEREST_CLIENT_ID` / `PINTEREST_CLIENT_SECRET` | [Pinterest](/docs/social/pinterest) one-click connect |
| `META_CLIENT_ID` / `META_CLIENT_SECRET` | [Facebook Pages](/docs/social/facebook) and [Instagram](/docs/social/instagram) — one app covers both |
| `THREADS_CLIENT_ID` / `THREADS_CLIENT_SECRET` | [Threads](/docs/social/threads) one-click connect (its own credential pair, same Meta App dashboard) |
| `X_CLIENT_ID` / `X_CLIENT_SECRET` | [X](/docs/social/x) one-click connect — note X charges per post once connected |

## MCP server

| Variable | Required | What it does |
|---|---|---|
| `ROSTERSEO_API_KEY` | Only for `apps/mcp-server` | Lets external AI tools reach project data over MCP. Generate one from **AI & MCP** in the app; shown once. See [AI & MCP](/docs/platform/ai-mcp). |

## Billing (planned, not yet implemented)

| Variable | Required | What it does |
|---|---|---|
| `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` | No — reserved | Placeholder for a planned hosted-SaaS billing mode. There's no Stripe integration in the codebase yet; setting these currently does nothing. |

## Observability (all optional, fully inert if unset)

| Variable | What it does |
|---|---|
| `SENTRY_DSN` / `NEXT_PUBLIC_SENTRY_DSN` | Error tracking — free DSN at [sentry.io](https://sentry.io) (or self-hosted). Same value; the `NEXT_PUBLIC_` one is just exposed to the browser. |
| `SENTRY_ORG` / `SENTRY_PROJECT` / `SENTRY_AUTH_TOKEN` | Only needed to upload source maps on build for better stack traces — skip to leave that step out entirely. |
| `NEXT_PUBLIC_POSTHOG_KEY` | Product analytics — free key at [posthog.com](https://posthog.com) (or self-hosted). |
| `NEXT_PUBLIC_POSTHOG_HOST` | PostHog ingestion host — defaults to PostHog Cloud US, change only if self-hosting PostHog. |
