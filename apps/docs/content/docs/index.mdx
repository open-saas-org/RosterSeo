Open-source SEO + AI-search-visibility platform. Combines a Screaming
Frog–style crawler/auditor, a keyword/SERP/competitor research suite, and
an AI-answer-engine (ChatGPT/Gemini/Perplexity) brand-visibility tracker,
plus GSC/GA4 integration so recommendations are grounded in real site
performance data, not just estimated SERP data.

## Status

A real, working Next.js dashboard across three pillars - SEO (Page
Analyzer, Keyword Research, Site Audit, Rank Tracking, Competitors, AI
Visibility, Local SEO), Publish (multi-platform blog publishing), and
Social - all backed by auth-protected API routes and Postgres persistence
with row-level tenant isolation. Every integration is a real API call,
never fabricated data - each one simply stays inert (and renders an honest
"not connected" state) until you set its API keys/credentials. See the
per-feature pages in the sidebar for what each module does and which
integration it depends on.
