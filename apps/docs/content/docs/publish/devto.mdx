---
title: Dev.to
description: Connect a Dev.to account using an API key
---

<Callout type="info">Manual only — no OAuth app to register.</Callout>

<Steps>
<Step>Go to [dev.to/settings/extensions](https://dev.to/settings/extensions).</Step>
<Step>Generate an **API Key** under the DEV Community API section.</Step>
<Step>In RosterSEO: **Publish → Connections → Dev.to** → paste the API Key (the account label field isn't used by the API — anything works).</Step>
</Steps>
