---
title: Ghost
description: Connect a Ghost site using an Admin API key
---

<Callout type="info">Manual only — no OAuth app to register.</Callout>

<Steps>
<Step>In Ghost Admin: **Settings → Integrations → Add custom integration**.</Step>
<Step>Name it (e.g. "RosterSEO"), then copy the **Admin API Key** shown (format `id:secret`).</Step>
<Step>In RosterSEO: **Publish → Connections → Ghost** → paste the Admin API Key and your **Site URL**.</Step>
</Steps>
