---
title: Hashnode
description: Connect a Hashnode publication using a Personal Access Token
---

<Callout type="info">Manual only — no OAuth app to register.</Callout>

<Steps>
<Step>Go to [hashnode.com/settings/developer](https://hashnode.com/settings/developer).</Step>
<Step>Generate a **Personal Access Token**.</Step>
<Step>Find your **Publication ID** — visible in your publication's dashboard URL, or via Hashnode's GraphQL API.</Step>
<Step>In RosterSEO: **Publish → Connections → Hashnode** → paste the token and Publication ID.</Step>
</Steps>
