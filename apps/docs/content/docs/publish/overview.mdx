Write once in the rich-text composer, pick which connected blogs to send it
to, then either publish immediately or schedule it — optionally letting AI
adapt the title/body per platform first.

## Publish now, schedule, or adapt per platform first

The composer's right-hand panel has an **"Edit content/image per
platform"** switch — off by default:

- **Off** (the common case): click **Publish now**, or pick a date/time on
  the inline calendar and click **Schedule** — the same title/body goes to
  every selected platform as-is.
- **On**: the buttons change to a single **"Continue to per-platform
  editing"** — this takes you to a review screen per platform where you
  can click **Respin with AI** to get an adapted version, or edit it by
  hand, before anything actually sends. Nothing is adapted automatically
  just by turning the switch on; respinning is a separate action per
  target.

<Callout type="warn">
Despite the switch's label, there's no per-platform **image** field on
that review screen today — only Title and Body. The cover image you set
in Compose goes to every platform unchanged either way.
</Callout>

## Viewing your posts

**Publish → Posts** has a **List / Calendar** toggle — List is the usual
status feed; Calendar shows scheduled and published posts on the day
they're set for, with a small colored dot per status.

## Two ways to connect a platform

Every platform below supports one of two connection methods — some support
both:

<Steps>
<Step>
**One-click OAuth** — click Connect, log into the platform, approve access.
Needs the app owner to register a developer app once (per platform below)
and set its Client ID/Secret in `.env`. Until that's set, the Connect
button is hidden and only the manual option shows.
</Step>
<Step>
**Manual token** — paste a token/API key you generated yourself on the
platform's own site. Works immediately, no `.env` change, no app
registration. Every platform page below explains exactly where to get that
token.
</Step>
</Steps>

<Callout type="info">
Registering an OAuth app is a one-time setup the *deployment owner* does —
after that, every user on that deployment gets the one-click Connect
button. The manual token is per-user, per-connection, no setup step for
anyone else.
</Callout>

If you're setting up OAuth, every platform uses the same redirect URL:

```
<your deployment URL>/api/integrations/blog/callback
```

## Platform templates

Composing usually means picking the same set of blogs every time — save
that combination once with **Save selection**, then reuse it from the
**preselected platforms** dropdown instead of re-checking each one.
