---
title: WordPress (self-hosted)
description: Connect a self-hosted WordPress site using an Application Password
---

<Callout type="info">Manual only — WordPress has no OAuth app to register.</Callout>

<Steps>
<Step>
In your WordPress admin: **Users → Profile → Application Passwords**.
</Step>
<Step>
Type a name for it (e.g. "RosterSEO"), click **Add New Application
Password**, and copy the generated password immediately — it's shown once.
</Step>
<Step>
In RosterSEO: **Publish → Connections → WordPress (self-hosted)** → enter
your **Username**, the **Application Password** you just copied, and your
**Site URL**.
</Step>
</Steps>
