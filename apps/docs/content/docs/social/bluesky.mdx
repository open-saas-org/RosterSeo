---
title: Bluesky
description: Connect a Bluesky account using an app password
---

<Callout type="info">Manual only — Bluesky has no OAuth app model.</Callout>

<Steps>
<Step>In the Bluesky app: **Settings → App Passwords → Add App Password**.</Step>
<Step>Name it (e.g. "RosterSEO") and copy the generated password.</Step>
<Step>In RosterSEO: **Social → Connections → Bluesky** → enter your handle (e.g. `you.bsky.social`) and the App Password.</Step>
</Steps>

Character limit: **300**.
