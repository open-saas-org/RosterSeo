---
title: Mastodon
description: Connect any Mastodon instance — no setup, it registers itself
---

<Callout type="info">Nothing to register, on any instance — the first Connect on a new instance registers an app for it automatically and reuses that app for every user afterward.</Callout>

<Steps>
<Step>In RosterSEO: **Social → Connections → Mastodon** → enter your instance URL (e.g. `https://mastodon.social`).</Step>
<Step>Click **Connect** → log in on your instance → approve access.</Step>
</Steps>

Character limit: **500**.

Prefer a manual token instead? Generate one under your instance's
**Settings → Development → New Application**, then paste it plus the
instance URL on the same Connections screen.
